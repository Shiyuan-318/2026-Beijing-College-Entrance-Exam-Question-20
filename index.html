第 20 题 函数与导数 详解 · 可交互演示

题 目

20. 已知函数 f(x) = x2 + mx − 4enx−1（其中 n 是整数），曲线 y = f(x) 在点 (−1, f(−1)) 处的切线方程为

4x + e2y + e2 + 8 = 0

  • 1求 m, n 的值；
  • 2求 f(x) 的极值点个数；
  • 3当 k > 0 时，讨论直线 y = kx − 1 与曲线 y = f(x) 的公共点个数。

切线的两个信息，正好解两个未知数

官方解法 · 用"切点满足曲线"和"切线斜率等于导数"两条信息联立。

  1. 把切线方程整理成 y = … 的形式，读出两件事： 4x + e2y + e2 + 8 = 0　⟹　y = −4e2x − 1 − 8e2 斜率为 −4/e2；再令 x = −1 得 y = −1 − 4e−2，这就是切点的纵坐标。
  2. 求导：f′(x) = 2x + m − 4nenx−1
  3. 切点在曲线上：f(−1) = 1 − m − 4e−n−1 = −1 − 4e−2，即 m + 4e−n−1 = 2 + 4e−2　①
  4. 切线斜率等于导数值：f′(−1) = −2 + m − 4ne−n−1 = −4e−2，即 m − 4ne−n−1 = 2 − 4e−2　②
  5. ① − ② 把 m 消掉：4(n+1)e−n−1 = 8e−2，两边同除 4： (n+1)e−(n+1) = 2e−2 这一步之后，指数和多项式混在一起，用普通方法解不出 n。
  6. 因为 n 是整数，令 t = n+1（也是整数），方程变成 te−t = 2e−2 ≈ 0.2707。考察 g(t) = te−t： · t ≤ 0 时 g(t) ≤ 0，不可能等于正数；
    · t = 1 时 g(1) = 1/e ≈ 0.3679 ≠ 0.2707；
    · t ≥ 1 时 g 单调递减，而 g(2) = 2e−2 正好相等。
    所以整数解只有 t = 2，即 n = 1。
  7. 代回 ①：m = 2 + 4e−2 − 4e−2 = 2。
大白话：切线一次性给了你两个条件——"碰在哪个点"和"斜多少"。函数里正好有 m、n 两个未知数，两个条件解两个未知数，不多不少。
结论：m = 2，n = 1，于是 f(x) = x2 + 2x − 4ex−1。

把指数"打包"，让 W 函数一次解完

同样的方程 (n+1)e−(n+1) = 2e−2，改用 Lambert W 显式解出全部实数解，就能看清"整数条件"过滤掉了什么。

先记住 W 函数：如果 w·ew = a，就把这个 w 记作 W(a)。
当 −1/e < a < 0 时，同一个 a 对应两个实数值，分别记作 W0(a) 和 W−1(a)。
  1. 前面 5 步与官方解法相同，仍然得到 (n+1)e−(n+1) = 2e−2
  2. 两边同乘 −1，让它变成 W 需要的样子：−(n+1)·e−(n+1) = −2e−2 令 w = −(n+1)，上式正是 w·ew = −2e−2。
  3. 注意右边 a = −2e−2 ≈ −0.2707 落在 (−1/e, 0) 内（−1/e ≈ −0.3679），所以 W 在这里有两个值。
  4. 解出两种可能： w1 = W−1(−2e−2) = −2　⟹　n + 1 = 2　⟹　n = 1 w2 = W0(−2e−2) ≈ −0.40638　⟹　n + 1 ≈ 0.40638　⟹　n ≈ −0.59362 第一个之所以恰好是 −2，是因为 (−2)·e−2 本来就等于 −2e−2，一眼能看出。第二个只能靠 W 算出来。
  5. 分别回代 ① 求 m： · n = 1：m = 2 + 4e−2 − 4e−2 = 2 ✔ 是整数；
    · n ≈ −0.59362：m = 2 + 4e−2 − 4e0.40638 ≈ −0.1229 ✘ 但 n 不是整数，被题目排除。
大白话：官方答案用"试整数"过关；W 函数的好处是把方程彻底解出来——它告诉我们实数范围内其实有两组解，只是第二组的 n 不是整数，所以不符合题目要求。
彩蛋：被淘汰的那个 n ≈ −0.59362，正好等于第 2 问里极小值点的横坐标 x1 ≈ −0.59362。原因是它们归根到底是同一个方程 u·e−u = 2e−2（把 u 换成 n+1 或 x+1 而已）。
结论：实数范围内有两组解，但题设 n 为整数，故只有 n = 1，m = 2。

不算出零点，只要"最大值是正的"

官方解法 · 极值点个数 = 导数变号零点的个数。f′(x) = 0 解不出来，那就先研究它自己的最大值。

  1. 由第 1 问，f(x) = x2 + 2x − 4ex−1，求导： f′(x) = 2x + 2 − 4ex−1
  2. 记 h(x) = f′(x)，再求一次导（这就是"二阶导"）： h′(x) = 2 − 4ex−1 = 0　⟹　ex−1 = 12　⟹　x = 1 − ln 2 ≈ 0.3069
  3. 看 h′ 的符号：x < 1 − ln 2 时 h′ > 0，x > 1 − ln 2 时 h′ < 0。
    所以 h（也就是 f′）在 (−∞, 1−ln2] 上递增、在 [1−ln2, +∞) 上递减——"先升后降"，只有一个最高点。
  4. 卡值（关键一步）：算出最高点的值 h(1 − ln 2) = 2(1 − ln 2) + 2 − 4·12 = 2(1 − ln 2) ≈ 0.6137 > 0
  5. 看两端：x → −∞ 时 2x+2 → −∞（指数项趋于 0），h → −∞；x → +∞ 时 −4ex−1 占主导，h → −∞。 "两端都是负的，中间最高点却是正的"——由零点存在定理，左右各出现一个零点，一共 2 个。
  6. 两个零点处 f′ 都改变符号（左端从负变正、右端从正变负），所以确实是极值点。
大白话：这叫"卡值"。我们并不需要知道零点具体在哪（那个方程解不出精确值），只要证明"导数的最大值大于 0、两端小于 0"，就能断定导数穿过横轴两次。
结论：f(x) 恰有 2 个极值点：x1 ≈ −0.5936（极小值点）、x2 = 1（极大值点）。

用"凸性"两头一夹

凸函数解法 · 用 ex 的切线不等式判断符号，用 f′ 的上凸性限制零点个数。

  1. et 是凸函数，图像永远在它的切线上方（只在切点处相等）。取 t = x − 1 在 t = 0 处的切线： ex−1 ≥ 1 + (x − 1) = x，等号仅在 x = 1 时成立
  2. 代进导数，一次就把右边的符号管住了： f′(x) = 2x + 2 − 4ex−1 ≤ 2x + 2 − 4x = 2 − 2x 所以 x ≥ 1 时 f′ ≤ 2 − 2x ≤ 0，且只有 x = 1 取到 0：右侧的零点就是 x = 1。
  3. 再找左边的零点：f′(0) = 2 − 4/e ≈ 0.5285 > 0（因为 e > 2），f′(−1) = −4e−2 < 0。 由零点存在定理，(−1, 0) 内至少还有一个零点（实际在 x1 ≈ −0.5936）。
  4. 再加一个"上限"：f″(x) = 2 − 4ex−1 是严格递减的，所以 f′ 严格上凸。 严格上凸的函数与横轴最多交 2 次——如果交了 3 次，中间那一段就会"凸"出来，与上凸矛盾。
  5. 合起来：至少 2 个零点、至多 2 个零点，所以恰好 2 个，且都在两侧变号。
大白话："ex 在切线上方"是凸函数最常用的一句话，考试可以当结论用；"上凸函数与横轴最多交 2 次"是这套解法的骨架。它和官方解法结论完全一样，只是一个靠"卡最大值"，一个靠"卡形状"。
结论：与官方解法一致，f(x) 恰有 2 个极值点。

除以 x，把方程"变成一个函数"

比值函数法 · 把交点方程两边除以 x，右边得到一个关于 x 的函数 G(x)；交点个数 = 水平线 y = k 与 G(x) 的交点个数。

  1. 写出交点方程，并把常数项配成完全平方，让式子"整块"起来： x2 + 2x − 4ex−1 = kx − 1　⟺　(x+1)2 − 4ex−1 = kx 记 F(x) = (x+1)2 − 4ex−1。
  2. 先确认 x = 0 不是解：F(0) = 1 − 4/e ≈ −0.47 ≠ 0。所以可以放心两边除以 x： k = F(x)x =: G(x)　(x ≠ 0)
  3. 先看 x > 0：一个交点也没有。注意到 F′(x) = 2x + 2 − 4ex−1 = f′(x) 这正是第 2 问研究过的导数！由第 2 问：f′ 在 (x1, 1) 上为正、在 (1, +∞) 上为负（而 x1 ≈ −0.59 < 0）。
    所以 F 在 (0, 1) 上递增、在 (1, +∞) 上递减，最大值是 F(1) = 4 − 4 = 0。
    于是 x > 0 时 F(x) ≤ 0，从而 G(x) = F(x)/x ≤ 0 < k——不可能相等。
  4. 再看 x < 0：恰好一个交点。先算 G 的导数： G′(x) = xF′(x) − F(x)x2 = x2 − 1 + 4ex−1(1 − x)x2 令 u = −x > 0，分子变成 P(u) = u2 − 1 + 4(u+1)e−u−1。
  5. 判断 P 的正负： P′(u) = 2u(1 − 2e−u−1) > 0　(u > 0 时 2e−u−1 < 2/e < 1) P(0) = 4/e − 1 ≈ 0.4715 > 0 所以 P(u) > 0，即 G′(x) > 0：G 在 (−∞, 0) 上严格递增。
  6. 看两端的走向：x → −∞ 时 F(x) ≈ x2，所以 G(x) ≈ x → −∞；x → 0− 时分子 F(0) < 0、分母 x < 0，所以 G(x) → +∞。 一个从 −∞ 升到 +∞ 的连续递增函数，和任意高度 k > 0 的水平线只交一次：存在唯一的 x0 < 0 使 G(x0) = k。

大白话：为什么叫"比值函数"？因为把方程除以 x 之后，等号右边是"两个式子相除"。它的单调性只要算一次导数就看得出来，比反复讨论二次导数省力得多。
图形直觉：所有直线 y = kx − 1 都经过同一个定点 (0, −1)；而曲线在 x > 0 的部分始终被它"压"在下面，所以交点只能出现在 x < 0 的一侧，而且只有一处。
结论：当 k > 0 时，直线 y = kx − 1 与曲线 y = f(x) 恰有 1 个公共点，且交点横坐标恒为负数。
